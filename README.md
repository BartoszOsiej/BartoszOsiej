## 🎮 Interactive

> Try Externum **live** — no install, no server, everything runs in your browser.

| Feature | Description | Link |
|---------|-------------|------|
| **Browser Playground** | Write & run Externum code in-browser via Pyodide (WASM). REPL with live language modification and custom functions | [▶ Try it](https://bartoszosiej.github.io/externum/) |
| **Issue-Command Bot** | Extend the language from GitHub Issues — `/run` executes binaries, `/define` evolves the language via comments (PR workflow) | [externum#8](https://github.com/BartoszOsiej/externum/pull/8) |
| **One-Click Verify** | `verify.sh` — single script to verify cosign signatures, SLSA attestation, and SBOM for any release artifact | [`verify.sh`](https://github.com/BartoszOsiej/externum/blob/main/verify.sh) |

  └──────────────┘    └────────────────┘    └────────────────┘
         │                                           │
         └───────────── stdout / stderr ◄───────────┘
